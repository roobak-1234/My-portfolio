# Roobak Kumar M - Portfolio

This is a modern personal portfolio website built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **Hero Section**: Introduces Roobak Kumar M, AI & Data Science Engineer, with social links and access to resume.
- **Experience**: Timeline detailing professional journey and virtual internships.
- **Certifications**: Grid displaying earned certificates (AWS, Azure, Google AI, HackerRank, etc.) with preview dialogs.
- **Responsive Design**: Mobile-friendly layout using custom CSS and tailwind grids.
- **Aesthetic Transitions**: Smooth loading animations powered by Framer Motion.

## How to Run Locally

Follow these steps to run the project in development mode:

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start the Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:8080](http://localhost:8080) (or the port specified in terminal) in your browser.

3. **Build for Production**
   ```bash
   npm run build
   ```

4. **Preview Production Build**
   ```bash
   npm run preview
   ```
